# Orion OS — Atualizações

Repositório oficial de distribuição do instalador e das atualizações do Orion OS.

## Instalação

Baixe a versão mais recente na seção **Releases**. O próprio Orion OS consulta o arquivo `manifest.json` para avisar quando houver uma nova versão disponível.

## Segurança

Cada versão publicada informa sua assinatura SHA-256 no `manifest.json`, usada pelo atualizador para validar o instalador antes de executá-lo.
